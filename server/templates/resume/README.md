# /server/templates/resume/

HTML resume templates rendered via Jinja2 + Chromium headless → PDF.

- Jinja2 delimiters rebound to `<% %>` or `[[ ]]` to avoid collision with HTML/CSS braces
- Data sourced from confirmed Layer 1 entities only — never raw AI output
- Tailoring = reorder + reweight existing facts against JD, never invent
